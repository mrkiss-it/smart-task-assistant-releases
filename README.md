# Smart Task Assistant — Releases

Public installers and update packages for **Smart Task Assistant**.

This repository contains **release artifacts only** (no application source code).

## Download

1. Open the [**Releases**](https://github.com/mrkiss-it/smart-task-assistant-releases/releases) page.
2. Download the latest asset for your platform (Windows).
3. Follow the notes included with that release.

## Notes

- Source code lives in a separate private repository.
- Always prefer assets attached to a GitHub Release over random copies of installers.
- Early builds may be incomplete launchers — read the release notes carefully.
