# Smart Task Assistant — Releases

Public installers and update packages for **Smart Task Assistant**.

This repository contains **release artifacts only** (no application source code).

## Download

1. Open the [**Releases**](https://github.com/mrkiss-it/smart-task-assistant-releases/releases) page.
2. Download **SmartTaskAssistant-Setup.exe** from the latest release (currently **v1.1.0**).
3. Double-click to install (no Administrator rights required). Installs under `%LOCALAPPDATA%\Programs\SmartTaskAssistant`.

## Requirements

- Windows 10/11
- Google Chrome (used for the desktop app window)

## Notes

- Source code lives in a separate private repository.
- Always prefer assets attached to a GitHub Release over random copies of installers.
- Google Calendar/Gmail connect needs a developer `.env.local` with OAuth client credentials in the install folder (see `.env.example` after install).
